## Agentic SFT TunningFactory — 配置系统与实践指南

### 一、配置系统架构

框架的配置系统基于 HuggingFace 的 `HfArgumentParser` + Python `dataclass`，支持三种输入方式，优先级从高到低：

```
命令行参数 > YAML 文件 > JSON 文件 > dataclass 默认值
```

#### 1.1 参数解析入口

`hparams/parser.py` 中的 `_parse_args()` 函数自动检测输入方式：

```python
def _parse_args(parser, args=None):
    if args is not None:
        return parser.parse_dict(args)           # Python Dict（API 调用）
    if sys.argv[1].endswith(".yaml"):
        return parser.parse_yaml_file(...)        # YAML 文件
    if sys.argv[1].endswith(".json"):
        return parser.parse_json_file(...)        # JSON 文件
    return parser.parse_args_into_dataclasses()    # 命令行参数
```

#### 1.2 五大参数类

| 参数类 | 文件 | 参数数量 | 核心参数 |
|-------|------|---------|---------|
| `ModelArguments` | `model_args.py` | ~40 | `model_name_or_path`, `quantization_bit`, `flash_attn`, `sequence_parallel_size` |
| `DataArguments` | `data_args.py` | ~40 | `dataset`, `template`, `cutoff_len`, `packing`, `streaming` |
| `FinetuningArguments` | `finetuning_args.py` | ~50 | `stage`, `finetuning_type`, `lora_rank`, `pref_beta`, `distill_loss_weight` |
| `GeneratingArguments` | `generating_args.py` | ~10 | `temperature`, `top_p`, `top_k`, `max_new_tokens` |
| `EvaluationArguments` | `evaluation_args.py` | ~5 | `task`, `n_shot`, `batch_size` |

此外还继承了 HuggingFace 的 `Seq2SeqTrainingArguments`，包含 `learning_rate`、`num_train_epochs`、`per_device_train_batch_size` 等标准训练参数。

### 二、核心参数详解

#### 2.1 模型参数 (`ModelArguments`)

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `model_name_or_path` | str | 必填 | 模型路径（本地路径 / HF repo / MOS URI） |
| `teacher_model_name_or_path` | str | None | 蒸馏时的 Teacher 模型路径 |
| `adapter_name_or_path` | str | None | LoRA adapter 路径，多个用逗号分隔 |
| `quantization_bit` | int | None | 量化位数（4 或 8） |
| `quantization_type` | str | `nf4` | 量化类型（`nf4` 或 `fp4`） |
| `double_quantization` | bool | True | 是否使用双重量化 |
| `flash_attn` | str | `fa2` | 注意力实现（`auto`/`disabled`/`sdpa`/`fa2`） |
| `rope_scaling` | str | None | RoPE 缩放策略（`linear`/`dynamic`/`yarn`） |
| `use_unsloth` | bool | False | 是否使用 Unsloth 加速 |
| `enable_liger_kernel` | bool | False | 是否启用 Liger Kernel 融合算子 |
| `sequence_parallel_size` | int | 1 | 序列并行 GPU 数（>1 启用 SP） |
| `sequence_parallel_mode` | str | `ulysses` | SP 模式（`ulysses`/`zigzag-ring`） |
| `resize_vocab` | bool | True | 是否自动调整词表大小 |
| `disable_gradient_checkpointing` | bool | False | 是否禁用梯度检查点 |

#### 2.2 数据参数 (`DataArguments`)

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `dataset` | str | None | 数据集名称（在 dataset_info.json 中注册） |
| `file_name` | str | None | 直接指定数据文件路径 |
| `dataset_name` | str | None | OpenLM Hub 数据集名称 |
| `template` | str | None | Prompt 模板名称（如 `qwen`/`llama2`） |
| `cutoff_len` | int | 2048 | 最大序列长度 |
| `train_on_prompt` | bool | False | 是否在 prompt 上也计算 loss |
| `mask_history` | bool | False | 是否只在最后一轮计算 loss |
| `packing` | bool | None | 是否启用样本拼接（PT 阶段自动启用） |
| `neat_packing` | bool | False | 是否使用 Block-Diagonal Attention Mask |
| `streaming` | bool | False | 是否流式加载数据 |
| `mix_strategy` | str | `concat` | 多数据集混合策略 |
| `preprocessing_num_workers` | int | None | 数据预处理并行数 |
| `prompt` | str | None | Alpaca 格式的 instruction 列名 |
| `query` | str | None | Alpaca 格式的 input 列名 |
| `response` | str | None | Alpaca 格式的 output 列名 |
| `messages` | str | None | ShareGPT 格式的 conversations 列名 |
| `image` | str | None | 图像列名 |
| `video` | str | None | 视频列名 |
| `audio` | str | None | 音频列名 |
| `enable_thinking` | bool | True | 是否启用推理模型的思考模式 |

#### 2.3 微调参数 (`FinetuningArguments`)

**通用参数**：

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `stage` | str | `sft` | 训练阶段（`pt`/`sft`/`rm`/`ppo`/`dpo`/`kto`/`distill`） |
| `finetuning_type` | str | `lora` | 微调方式（`full`/`freeze`/`lora`/`reft`） |
| `use_turbo` | bool | False | 是否使用 Turbo 加速模式 |
| `plot_loss` | bool | False | 是否绘制 Loss 曲线 |

**LoRA 参数**：

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `lora_rank` | int | 8 | LoRA 秩 |
| `lora_alpha` | int | None | LoRA 缩放因子（默认 = 2 × lora_rank） |
| `lora_dropout` | float | 0.0 | LoRA Dropout 率 |
| `lora_target` | str | `all` | 目标模块（`all` 或逗号分隔的模块名） |
| `use_dora` | bool | False | 是否使用 DoRA |
| `use_rslora` | bool | False | 是否使用 rsLoRA |
| `additional_target` | str | None | 额外可训练模块 |

**Freeze 参数**：

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `freeze_trainable_layers` | int | 2 | 可训练层数（正数=最后N层，负数=前N层） |
| `freeze_trainable_modules` | str | `all` | 可训练模块名 |
| `freeze_module_prefix` | str | None | 冻结模块前缀（如 `vision_tower`） |

**DPO/RLHF 参数**：

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `pref_beta` | float | 0.1 | DPO 的 β 参数 |
| `pref_loss` | str | `sigmoid` | 偏好损失类型 |
| `pref_ftx` | float | 0.0 | SFT 损失混合系数 |
| `ref_model` | str | None | 参考模型路径 |
| `reward_model` | str | None | 奖励模型路径 |

**蒸馏参数**：

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `distill_loss_weight` | float | 0.5 | KD 损失权重 α |
| `kd_temperature` | float | 1.0 | Student 温度 |
| `teacher_temperature` | float | 1.0 | Teacher 温度 |
| `kd_objective` | str | `forward_kl` | KD 目标函数 |

### 三、数据集配置系统

#### 3.1 `dataset_info.json` 格式

所有通过 `--dataset` 参数引用的数据集都需要在 `data/dataset_info.json` 中注册：

```json
{
  "my_dataset": {
    "file_name": "my_data.json",           // 本地文件路径
    "formatting": "alpaca",                 // 数据格式：alpaca 或 sharegpt
    "columns": {                            // 列名映射
      "prompt": "instruction",
      "query": "input",
      "response": "output",
      "history": "history"
    }
  },
  "my_sharegpt_dataset": {
    "file_name": "my_sharegpt.json",
    "formatting": "sharegpt",
    "columns": {
      "messages": "conversations"
    },
    "tags": {                               // ShareGPT 角色标签
      "role_tag": "role",
      "content_tag": "content",
      "user_tag": "user",
      "assistant_tag": "assistant"
    }
  },
  "hf_dataset": {
    "hf_hub_url": "username/dataset_name",  // HuggingFace Hub 数据集
    "ms_hub_url": "username/dataset_name"   // ModelScope Hub 数据集
  }
}
```

#### 3.2 直接文件路径模式

不需要注册 `dataset_info.json`，直接指定文件路径和列名：

```bash
python src/train_bash.py \
    --file_name data/my_data.json \
    --prompt instruction \
    --query input \
    --response output
```

#### 3.3 Alpaca 数据格式

```json
[
  {
    "instruction": "请翻译以下英文句子",
    "input": "Hello, how are you?",
    "output": "你好，你怎么样？"
  }
]
```

字段说明：
- `instruction`：任务指令（对应 `--prompt` 参数）
- `input`：补充输入（对应 `--query` 参数），可为空
- `output`：期望输出（对应 `--response` 参数）
- `history`：历史对话（可选），格式为 `[["q1", "a1"], ["q2", "a2"]]`

#### 3.4 ShareGPT 数据格式

```json
[
  {
    "conversations": [
      {"from": "human", "value": "你好"},
      {"from": "gpt", "value": "你好！有什么可以帮助你的吗？"},
      {"from": "human", "value": "请介绍一下自己"},
      {"from": "gpt", "value": "我是一个AI助手..."}
    ]
  }
]
```

#### 3.5 偏好数据格式（DPO/RM）

```json
[
  {
    "instruction": "写一首关于春天的诗",
    "input": "",
    "chosen": "春风拂面花自开，万物复苏百鸟来...",
    "rejected": "春天来了天气好，出去玩很开心..."
  }
]
```

#### 3.6 多模态数据格式

```json
[
  {
    "instruction": "描述这张图片的内容",
    "input": "",
    "output": "图片中展示了一座古老的城市...",
    "image": ["path/to/image.jpg"]
  }
]
```

支持的多模态字段：`image`（图片路径列表）、`video`（视频路径列表）、`audio`（音频路径列表）。

在文本中使用占位符 `<image>`、`<video>`、`<audio>` 标记多模态内容的插入位置。

### 四、训练脚本实践指南

#### 4.1 LoRA SFT（最常用）



### 六、超参数调优建议

#### 6.1 学习率

| 微调方式 | 推荐学习率 | 说明 |
|---------|-----------|------|
| Full SFT | 1e-5 ~ 5e-5 | 全参数训练，学习率不宜过大 |
| LoRA SFT | 1e-4 ~ 5e-4 | LoRA 参数少，可用较大学习率 |
| QLoRA SFT | 1e-4 ~ 2e-4 | 与 LoRA 类似 |
| DPO | 1e-6 ~ 5e-6 | 偏好优化需要小学习率 |
| PPO | 1e-6 ~ 1e-5 | 强化学习需要小学习率 |
| 蒸馏 | 1e-5 ~ 5e-5 | 与 Full SFT 类似 |

#### 6.2 LoRA 参数

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| `lora_rank` | 8~64 | 越大表达能力越强，但参数量越多 |
| `lora_alpha` | 2 × rank | 标准设置 |
| `lora_target` | `all` | 对所有线性层应用 LoRA，效果最好 |
| `lora_dropout` | 0.0~0.1 | 小数据集可适当增大 |

#### 6.3 Batch Size 与梯度累积

```
有效 batch size = per_device_batch_size × num_gpus × gradient_accumulation_steps
```

推荐有效 batch size：
- SFT：32~128
- DPO：16~64
- PPO：8~32

显存不足时，减小 `per_device_train_batch_size`，增大 `gradient_accumulation_steps`。

#### 6.4 序列长度

| 场景 | 推荐 cutoff_len |
|------|----------------|
| 短文本 SFT | 512~1024 |
| 通用 SFT | 2048~4096 |
| 长文本 SFT | 8192~32768 |
| 代码生成 | 4096~8192 |

#### 6.5 训练轮数

| 数据量 | 推荐 epochs |
|--------|------------|
| < 1K 样本 | 5~10 |
| 1K~10K 样本 | 3~5 |
| 10K~100K 样本 | 1~3 |
| > 100K 样本 | 1~2 |

### 七、常见问题与解决方案

#### 7.1 显存不足 (OOM)

**解决方案优先级**：
1. 减小 `per_device_train_batch_size`
2. 减小 `cutoff_len`
3. 启用梯度检查点（默认已启用）
4. 使用 QLoRA（`--quantization_bit 4`）
5. 使用 DeepSpeed ZeRO-3
6. 启用 CPU Offload

#### 7.2 Loss 不下降

**排查步骤**：
1. 检查 `--template` 是否与模型匹配
2. 检查数据格式是否正确（查看训练日志中的 example 输出）
3. 检查学习率是否合适
4. 检查 `--train_on_prompt` 设置是否符合预期

#### 7.3 生成质量差

**排查步骤**：
1. 检查训练数据质量
2. 检查是否过拟合（eval_loss 上升）
3. 调整推理参数（temperature、top_p）
4. 增加训练数据量或减少训练轮数

#### 7.4 多卡训练卡住

**排查步骤**：
1. 检查 NCCL 环境变量
2. 检查网络连通性
3. 设置 `NCCL_DEBUG=INFO` 查看通信日志
4. 检查是否有 GPU 故障

#### 7.5 Checkpoint 恢复

```bash
python src/train_bash.py \
    ... \
    --resume_from_checkpoint output/checkpoint-500
```

DeepSpeed 的 checkpoint 恢复需要保持相同的 GPU 数量和 DeepSpeed 配置。
