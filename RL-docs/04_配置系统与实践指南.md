## ROLL 配置系统与实践指南

### 一、配置系统架构

ROLL 使用 **Hydra + Python dataclass** 的配置系统，用户通过 YAML 文件定义完整的训练流程，框架自动将 YAML 映射为 Python 对象。

```
配置层次结构:
┌──────────────────────────────────────────────┐
│  YAML 配置文件 (examples/*.yaml)              │
│  ↓ Hydra 解析                                │
│  Pipeline Config (RLVRConfig / AgenticConfig) │
│  ├── BaseConfig (全局配置)                     │
│  ├── WorkerConfig (角色配置)                   │
│  │   ├── ModelArguments (模型参数)              │
│  │   ├── TrainingArguments (训练参数)           │
│  │   ├── DataArguments (数据参数)               │
│  │   ├── GeneratingArguments (生成参数)         │
│  │   └── StrategyArguments (策略参数)           │
│  └── PPOConfig / RL 策略配置                   │
└──────────────────────────────────────────────┘
```

### 二、配置类详解

#### 2.1 BaseConfig（`roll/configs/base_config.py`）

全局配置，控制训练的整体行为：

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `exp_name` | str | 脚本名 | 实验名称 |
| `seed` | int | 42 | 随机种子 |
| `max_steps` | int | 500 | 最大训练步数 |
| `save_steps` | int | 50 | 检查点保存间隔 |
| `eval_steps` | int | 10 | 验证间隔 |
| `logging_steps` | int | 1 | 日志间隔 |
| `rollout_batch_size` | int | 128 | 每步 rollout 的 prompt 数量 |
| `prompt_length` | int | 1024 | prompt 最大长度 |
| `response_length` | int | None | response 最大长度 |
| `sequence_length` | int | None | 总序列最大长度 |
| `num_nodes` | int | 1 | 节点数 |
| `num_gpus_per_node` | int | 8 | 每节点 GPU 数 |
| `output_dir` | str | ./output | 输出目录 |
| `track_with` | str | tensorboard | 追踪器类型 |
| `resume_from_checkpoint` | bool/str | False | 断点续训 |
| `rpc_timeout` | int | 3600 | RPC 超时时间（秒） |

**注意**: `response_length` 和 `sequence_length` 二选一设置。如果设置了 `response_length`，则 `sequence_length = prompt_length + response_length`。

#### 2.2 WorkerConfig（`roll/configs/worker_config.py`）

每个角色（Actor Train / Actor Infer / Reference / Critic / Reward）都有独立的 WorkerConfig：

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `name` | str | None | 角色名称 |
| `worker_cls` | str | None | Worker 类路径 |
| `device_mapping` | str/List | None | GPU 设备映射 |
| `num_gpus_per_worker` | int | 1 | 每个 Worker 的 GPU 数 |
| `world_size` | int | None | Worker 数量（自动计算） |
| `model_update_frequency` | int | 1 | 模型同步频率 |
| `model_update_method` | str | nccl | 模型同步方式 |
| `infer_batch_size` | int | 16 | 推理 batch size |
| `use_remove_padding` | bool | False | 移除尾部 padding |
| `use_dynamic_batching_in_train` | bool | False | 训练动态 batching |
| `use_sequence_packing` | bool | False | 序列打包 |
| `offload_nccl` | bool | False | NCCL 缓冲区 offload |

**world_size 自动计算**: `world_size = len(device_mapping) / num_gpus_per_worker`

#### 2.3 StrategyArguments

控制训练/推理后端的选择和配置：

```yaml
strategy_args:
  strategy_name: megatron_train  # 策略名称
  strategy_config:               # 策略特定配置
    tensor_model_parallel_size: 2
    pipeline_model_parallel_size: 1
    expert_model_parallel_size: 1
    use_distributed_optimizer: true
    recompute_granularity: full
```

**可选的 strategy_name**:
| 名称 | 用途 | 说明 |
|------|------|------|
| `deepspeed_train` | 训练 | DeepSpeed ZeRO 训练 |
| `megatron_train` | 训练 | Megatron 5D 并行训练 |
| `deepspeed_infer` | 推理 | DeepSpeed 推理 |
| `megatron_infer` | 推理 | Megatron 推理 |
| `hf_infer` | 推理 | HuggingFace 原生推理 |
| `vllm` | 推理 | vLLM 推理引擎 |
| `sglang` | 推理 | SGLang 推理引擎 |
| `rtp` | 推理 | RTP 推理 |
| `mock_infer` | 测试 | Mock 推理（测试用） |

#### 2.4 ModelArguments（`roll/configs/model_args.py`）

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `model_name_or_path` | str | None | 模型路径或 HF/ModelScope ID |
| `dtype` | str | bf16 | 模型精度 (fp32/bf16/fp16) |
| `attn_implementation` | str | None | 注意力实现 (sdpa/fa2/auto) |
| `disable_gradient_checkpointing` | bool | False | 禁用梯度检查点 |
| `lora_rank` | int | 8 | LoRA 秩 |
| `lora_target` | str | None | LoRA 目标模块 |
| `lora_alpha` | int | None | LoRA alpha（默认 2*rank） |
| `freeze_module_prefix` | str | None | 冻结模块前缀 |
| `ulysses_size` | int | 1 | Ulysses 注意力组大小 |

#### 2.5 TrainingArguments（`roll/configs/training_args.py`）

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `learning_rate` | float | 5e-5 | 学习率 |
| `weight_decay` | float | 0.0 | 权重衰减 |
| `per_device_train_batch_size` | int | 8 | 每设备训练 batch size |
| `gradient_accumulation_steps` | int | 1 | 梯度累积步数 |
| `warmup_steps` | int | 0 | 预热步数 |
| `warmup_ratio` | float | 0.0 | 预热比例 |
| `lr_scheduler_type` | str | linear | 学习率调度器 |
| `num_train_epochs` | float | 1.0 | 训练轮数 |
| `bf16` | bool | False | 使用 BF16 混合精度 |

#### 2.6 GeneratingArguments（`roll/configs/generating_args.py`）

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `max_new_tokens` | int | 512 | 最大生成 token 数 |
| `temperature` | float | 1.0 | 采样温度 |
| `top_p` | float | 1.0 | Top-p 采样 |
| `top_k` | int | 50 | Top-k 采样 |
| `num_return_sequences` | int | 1 | 每个 prompt 生成的序列数 |
| `num_beams` | int | 1 | Beam search 数量 |

### 三、YAML 配置文件实战

#### 3.1 RLVR 配置示例（Qwen2.5-7B）

```yaml
# === 全局配置 ===
exp_name: "qwen2.5-7B-rlvr"
seed: 42
max_steps: 500
save_steps: 100
eval_steps: 10

# === 序列长度 ===
prompt_length: 2048
response_length: 4096

# === RL 策略 ===
num_return_sequences_in_group: 8    # 每个 prompt 生成 8 个 response
ppo_epochs: 1                       # 每步训练 1 个 epoch
adv_estimator: "reinforce"          # 使用 Reinforce++ 算法

# === Clip 参数 ===
value_clip: 0.5
reward_clip: 10
advantage_clip: 2.0
dual_clip_loss: true

# === 数据掩码 ===
max_len_mask: true                  # 过滤达到最大长度的样本
difficulty_mask: true               # 过滤过于简单/困难的样本
difficulty_low_threshold: 0.1
difficulty_high_threshold: 0.95

# === Advantage ===
whiten_advantages: true             # Advantage 白化

# === 模型 ===
pretrain: Qwen/Qwen2.5-7B
reward_pretrain: Qwen/Qwen2.5-7B

# === GPU 资源 ===
num_gpus_per_node: 8

# === Actor Train ===
actor_train:
  model_args:
    dtype: bf16
    disable_gradient_checkpointing: false
  training_args:
    learning_rate: 1.0e-6
    per_device_train_batch_size: 1
    gradient_accumulation_steps: 32
    warmup_steps: 20
  data_args:
    template: qwen2_5
    file_name:
      - data/math_deepmath_deal.jsonl
      - data/code_KodCode_data.jsonl
    domain_interleave_probs:
      math_rule: 0.5
      code_sandbox: 0.5
  strategy_args:
    strategy_name: megatron_train
    strategy_config:
      tensor_model_parallel_size: 1
      pipeline_model_parallel_size: 1
      use_distributed_optimizer: true
      recompute_granularity: full
  device_mapping: list(range(0,16))

# === Actor Infer ===
actor_infer:
  model_args:
    dtype: bf16
  generating_args:
    max_new_tokens: ${response_length}
    temperature: 0.99
    top_p: 0.99
    num_return_sequences: ${num_return_sequences_in_group}
  strategy_args:
    strategy_name: vllm
    strategy_config:
      gpu_memory_utilization: 0.8
      max_model_len: 8000
  device_mapping: list(range(0,12))

# === Reference ===
reference:
  model_args:
    dtype: bf16
  strategy_args:
    strategy_name: megatron_infer
    strategy_config:
      tensor_model_parallel_size: 1
  device_mapping: list(range(0,16))

# === Rewards ===
rewards:
  math_rule:
    worker_cls: roll.pipeline.rlvr.rewards.math_rule_reward_worker.MathRuleRewardWorker
    tag_included: [deepmath_103k]
    world_size: 8
  code_sandbox:
    worker_cls: roll.pipeline.rlvr.rewards.code_sandbox_reward_worker.CodeSandboxRewardWorker
    tag_included: [KodCode]
    world_size: 8
```

### 五、启动方式

#### 5.1 单节点启动

```bash
# 方式一：直接运行
python -m roll.pipeline.rlvr.rlvr_pipeline \
    --config-path=../../examples/qwen2.5-7B-rlvr_megatron \
    --config-name=rlvr_config

# 方式二：使用启动脚本
bash examples/qwen2.5-7B-rlvr_megatron/run_rlvr_pipeline.sh
```

#### 5.2 多节点启动

```bash
# 在主节点启动 Ray head
ray start --head --port=6379

# 在工作节点加入集群
ray start --address=<head_ip>:6379

# 运行训练
python -m roll.pipeline.rlvr.rlvr_pipeline \
    --config-name=rlvr_config \
    num_nodes=4 \
    num_gpus_per_node=8
```

#### 5.3 提交到集群

```bash
# 使用 submit_pipeline.sh 提交到 Kubernetes/PAI 集群
bash examples/qwen2.5-7B-rlvr_megatron/submit_pipeline.sh
```

### 六、实践指南

#### 6.1 GPU 资源规划

**原则**: 训练 GPU ≥ 推理 GPU，Reference 可与训练共享 GPU。

| 模型规模 | 推荐配置 | 说明 |
|---------|---------|------|
| **0.5B-3B** | 8 GPU | Train 8 + Infer 8（colocated） |
| **7B** | 16-32 GPU | Train 16 + Infer 12 + Ref 16 |
| **14B-32B** | 32-64 GPU | Train 32(TP2) + Infer 16(TP2) + Ref 32 |
| **72B** | 64-128 GPU | Train 64(TP4) + Infer 32(TP4) + Ref 64 |
| **MoE 235B** | 128+ GPU | Train 128(TP4+EP4) + Infer 64(TP4) |

#### 6.2 Batch Size 计算

```
Global Batch Size = rollout_batch_size × num_return_sequences_in_group
                  = 64 × 8 = 512 (samples per step)

Training Batch Size = per_device_train_batch_size × gradient_accumulation_steps × dp_size
                    = 1 × 32 × 16 = 512 (应等于 Global Batch Size)
```

**关键约束**: `rollout_batch_size × num_return_sequences = per_device_batch × grad_accum × dp_size`

#### 6.3 学习率选择

| 场景 | 推荐学习率 | 说明 |
|------|-----------|------|
| RLVR (7B) | 1e-6 ~ 5e-7 | 较小的学习率，避免灾难性遗忘 |
| RLVR (72B) | 5e-7 ~ 1e-7 | 更大的模型需要更小的学习率 |
| Agentic RL | 1e-6 ~ 1e-5 | 可以稍大，因为任务差异大 |
| Distill | 5e-5 ~ 1e-5 | 标准 SFT 学习率 |
| DPO | 5e-7 ~ 1e-6 | 类似 RLVR |

#### 6.4 常见问题排查

##### 训练不稳定
```yaml
# 1. 降低学习率
learning_rate: 5e-7

# 2. 增大 gradient_accumulation_steps
gradient_accumulation_steps: 64

# 3. 启用 reward_clip
reward_clip: 10

# 4. 启用 advantage_clip
advantage_clip: 2.0

# 5. 启用 dual_clip_loss
dual_clip_loss: true
```

##### 显存不足
```yaml
# 1. 启用梯度检查点
model_args:
  disable_gradient_checkpointing: false

# 2. 使用 Megatron TP 并行
strategy_config:
  tensor_model_parallel_size: 2

# 3. 降低推理显存占用
strategy_config:
  gpu_memory_utilization: 0.6

# 4. 启用 NCCL offload
offload_nccl: true

# 5. 使用 remove_padding
use_remove_padding: true
```

##### Rollout 速度慢
```yaml
# 1. 使用异步 rollout
generate_opt_level: 1

# 2. 增加推理 GPU
actor_infer:
  device_mapping: list(range(0,16))

# 3. 使用 FP8 推理
strategy_config:
  enable_fp8: true

# 4. 启用动态采样
use_additional_prompts: true
max_running_requests: 256
```

##### 奖励全为 0
```
1. 检查 reward worker 的 tag_included 是否与数据的 tag 匹配
2. 检查 ground_truth 字段是否正确
3. 检查 reward worker 的日志输出
4. 单独测试 reward worker 的计算逻辑
```

### 七、性能优化清单

| 优化项 | 配置 | 预期效果 |
|--------|------|---------|
| 异步 Rollout | `generate_opt_level: 1` | 消除长尾延迟 |
| Sequence Packing | `use_sequence_packing: true` | 减少 padding 浪费 |
| Dynamic Batching | `use_dynamic_batching_in_train: true` | 减少 padding 浪费 |
| Remove Padding | `use_remove_padding: true` | 减少无效计算 |
| 激活重计算 | `recompute_granularity: full` | 节省显存 |
| 分布式优化器 | `use_distributed_optimizer: true` | 节省显存 |
| NCCL Offload | `offload_nccl: true` | 节省显存 |
| FP8 推理 | `enable_fp8: true` | 加速推理 |
| LoRA | `lora_rank: 64` | 减少训练参数量 |
